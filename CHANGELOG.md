# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-09

### Added
- Initial release of Prompt Injection LLM Benchmark
- Dataset: 250 prompt injection attack samples
- 5 attack categories with 14 subcategories
- 14 languages supported
- Support for 11 LLM systems
- Comprehensive evaluation pipeline
- Statistical analysis and metrics computation
- Automated figure generation
- Complete documentation and examples
- GitHub Actions CI/CD
- Full test suite
- Configuration management system

### Features
- DatasetLoader for CSV/JSON loading
- DatasetValidator for schema validation
- ModelRegistry for managing LLM integrations
- Evaluator for running benchmark attacks
- Metrics computation (ASR, F1, MCC, etc.)
- One-command pipeline execution
- Publication-quality output

### Documentation
- Comprehensive README
- Installation guide
- Usage documentation
- Threat model documentation
- Reproducibility guide
- API reference
- Examples and tutorials
